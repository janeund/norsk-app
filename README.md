# Norsk — learn Norwegian

A web app for learning Norwegian (Bokmål): flashcards with spaced repetition, quizzes and bite-sized grammar lessons.

## Features

- **Flashcards** with an SM-2-style spaced repetition algorithm
- **Quizzes**: multiple choice or typed answers (with æ / ø / å buttons)
- **Grammar lessons** with tables, examples and self-checks
- **Gamification**: XP and daily streak
- Responsive dashboard for desktop and mobile; progress saved in the browser

## Tech stack

React 19 · TypeScript · Vite · CSS (Flexbox / Grid) · localStorage

## Run locally

```bash
npm install
npm run dev
```
